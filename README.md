# Salary Prediction Using Regression

This practical predicts salary from years of experience.

## Models used
- Linear Regression
- Ridge Regression
- Gradient Descent for Linear Regression (implemented with NumPy)

## Run the program
Keep `Salary_Data.csv` in the same folder as `regression_models.py`, then run:

```bash
pip install -r requirements.txt
python regression_models.py
```

The program prints MAE, MSE, RMSE and R2 for each model. It saves the metric table and graphs in the `outputs` folder.

The dataset is small and is used for learning and demonstration only.
